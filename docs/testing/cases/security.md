# 会话授权与访问控制

会话 cookie 只发给 `Accept` 含 `text/html` 的文档请求（`opensSessionFor`），脚本访问要伪装成浏览器文档请求，
或用 `X-Instance-Secret` 走 `POST /internal/v1/session/link`。详见 [操作指南](../guide.md#5-观察与操作手段)。

| ID | 层 | 步骤 | 期望 |
| --- | --- | --- | --- |
| D3-5 | 回归 | 设置 → 安全 → 退出登录；用 `--listen 0.0.0.0:<端口>` 启动 | 退出后回到登录页；非回环地址启动被拒绝 |
| D3-6 | 回归 | 从其他本地端口的页面发请求；不带 Origin 调写接口；书签打开；核心重启后再打开 | 前两者 403；后两者直接进入 |
| D2-8 | 回归 | key 不落盘：在数据根（除 `runtime/credentials/`）、日志、录制、API 响应、SQLite 中搜索密钥 | 一处都没有。搜索时用脚本比对，不打印密钥原文，需要对照时只用掩码（前 4 位 + `****` + 后 2 位） |
