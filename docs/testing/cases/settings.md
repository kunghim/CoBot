# 设置、用量与记忆

设置页共 9 个分区：通用、外观、角色、Codex 引擎、模型供应商、默认模型、协作与预算、已归档团队、关于（头像库卡片在外观分区里）。
每个写操作都用 `GET /api/v1/settings` 回读确认落库，不以「页面看起来变了」为准；测完把改过的值还原，并回读确认。
「安全」分区只做读侧验证，不点「退出 CoBot」（会登出真实会话）。
