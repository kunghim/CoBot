# Codex 引擎与版本兼容

引擎只使用 ChatGPT 桌面端内置的 Codex；自动发现和手动 `enginePath` 都不接受独立 CLI，也不回退到 `PATH`。
实现里没有最低版本门禁（旧版 Codex 因带不动控制进程在握手时失败，报「引擎控制进程不可用」）。
最低支持版本不单列用例（原 E1）：它由门禁 A4 和 [接力](relay.md)、[模型](models.md)的真实用例覆盖。

| ID | 层 | 步骤 | 期望 |
| --- | --- | --- | --- |
| E2 | 回归 | 在 `$R/real` 的**另一份副本**里留空 `enginePath`，检查自动发现的路径属于 ChatGPT 桌面端；再用设置接口显式指向同一应用内的引擎。macOS 按应用包身份发现，Windows 按 Store 包元数据发现，不猜安装目录。只读使用，不复制、不安装、不改 PATH | 两种方式均握手通过；`cobot trace protocol` 对比基线，差异逐项说明；真实跑通一个三环小需求；显式指定独立 CLI 时显示缺少桌面端引擎，不启动该 CLI |
| E3 | 回归 | 最新正式版 ChatGPT 桌面端内置的 Codex | 需要下载或更新桌面端时先问用户。不做就在结论里写明实际验证过的版本 |
| EN-1 | 回归 | 设置页「Codex 引擎」分区 | 显示版本、可执行文件路径、协议 app-server/stdio、安全钩子「已授权」；`GET /api/v1/engine` 与页面一致 |
