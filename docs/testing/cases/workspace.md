# 团队浏览器与工作区

团队浏览器用本机 Edge，每个团队一个独立 profile。

| ID | 层 | 步骤 | 期望 |
| --- | --- | --- | --- |
| D3-1 | 回归 | 成员打开网页；用户自己开一个标签并输入地址；切换四种视口（desktop/tablet/phone 或自定义宽高，`POST /browser/tabs/{tab}/viewport`）；刷新页面 | 成员的页面自动成为标签；用户标签的标题跟随页面；视口切换实时生效；刷新后标签和宽度恢复 |
| D3-2 | 回归 | 让成员打开 `edge://settings`、上传 `C:/Windows/win.ini`、往密码框输入 | 前两个被工具拒绝；密码框输入被拦截（工具层），成员如实回报 |
| D3-3 | 回归 | 关闭团队，再正常停止核心 | Edge、Codex 进程全部退出；团队目录里没有临时浏览器配置残留 |
| D3-7 | 回归 | 1024 和 760 宽打开工作区 | 对话区不小于 420px，按规则让位 |
