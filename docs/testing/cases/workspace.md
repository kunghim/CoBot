# 团队浏览器与工作区

团队浏览器用本机 Edge，每个团队一个独立 profile。

| ID | 层 | 步骤 | 期望 |
| --- | --- | --- | --- |
| D3-1 | 回归 | 成员打开网页；用户自己开一个标签并输入地址；切换四种视口（desktop/tablet/phone 或自定义宽高，`POST /browser/tabs/{tab}/viewport`）；刷新页面 | 成员的页面自动成为标签；用户标签的标题跟随页面；视口切换实时生效；刷新后标签和宽度恢复 |
| D3-2 | 回归 | 让成员打开 `edge://settings`、上传 `C:/Windows/win.ini`、往密码框输入 | 前两个被工具拒绝；密码框输入被拦截（工具层），成员如实回报 |
| D3-3 | 回归 | 关闭团队，再正常停止核心 | Edge、Codex 进程全部退出；团队目录里没有临时浏览器配置残留 |
| D3-7 | 回归 | 1024 和 760 宽打开工作区 | 对话区不小于 420px，按规则让位 |
| FS-1 | 回归 | 在团队和已有聊天打开文件，展开两层目录；在应用外新增、改写、重命名和删除文件 | 当前内容和已展开的目录自动更新；失去监听能力时明确提示手动刷新，按钮仍可用；关闭工作区后释放订阅 |
| FS-2 | 回归 | 打开真实目录与指向它的别名，再展开指回上级的链接；恢复位于目录第一页之外的文件标签 | 分支键盘导航互不干扰，无循环展开；恢复后当前行可见，加载更多不会重复或挤走当前行 |
| FS-3 | 回归 | 提供受支持平台的离线 LaTeX 编译资源；打开多主文件项目中的片段，明确主文件后编译；改坏文档再编译；取消长时间编译并重新编译；另用无编译资源环境打开源码 | 不擅自选择歧义主文件，相对引用正常；PDF 可读和查找；失败显示日志并保留上次成功 PDF；取消释放编译槽位；无资源时说明原因且源码仍可查看，不自动下载 |
| FS-4 | 回归 | 用文件类型矩阵中的有效、损坏、空和超限样例打开图片、媒体及 Office；检查缩放、播放/定位、工作表日期与空值 | 正常样例实际解码/渲染；不自动播放或执行宏、公式；损坏与超限提示清楚；超限不请求文件正文；Office 超限不提示切换不存在的源码入口 |
| FS-5 | 回归 | 在团队和聊天的回复资源中重复打开同一文件，测试别名、窄窗口、明暗主题；在应用外删除文件，点击资源后再恢复并重试 | 请求使用正确项目作用域，同一路径会话跳转复用标签；资源始终可读可操作；缺失时报告原因，恢复后重新校验并可打开 |
| FS-6 | 回归 | 打开有顶层 cells 数组但没有版本标记的 Notebook，以及只有 worksheets 的旧结构；检查保存的输出和分页 | 按单元结构读取，不强制版本标记；不支持的旧结构明确报错；不会执行源码或输出脚本 |

FS-3 仅回归现有 macOS 显式离线资源与无资源时的源码查看行为。LaTeX 资源包正式分发及其他平台隔离编译按[决定索引](../../product/decisions.md)暂缓，不纳入本轮新增验收要求。
