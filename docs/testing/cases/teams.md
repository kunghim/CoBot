# 团队与成员

| ID | 层 | 步骤 | 期望 |
| --- | --- | --- | --- |
| TM-1 | 冒烟 | 打开「新建团队」对话框，先不填；再填一个不存在的工作目录；再填正确的 | 列出 5 个角色（项目经理必选，其余可选）、工作目录选择器、团队名称输入；缺目录或名称时「创建」禁用；目录不存在时明确报「工作目录不存在：…」，不静默接受。小视口（约 375 宽）下错误提示曾被裁掉（P3，未处理），测到时只记录是否仍然如此 |
| C6 | 冒烟 | **建团队**：工作目录选带中文和空格的路径，例如 `$R/项目 一`；勾选全部五个角色 | 创建成功，五个成员齐全，自动进入项目经理会话；重启核心后都还在。默认只创建项目经理，其余角色要手动勾选 |
| TM-2 | 回归 | 归档一个空闲团队；在设置页「已归档团队」里找到它；再恢复 | 只有空闲团队能归档（有待处理审批、未完成任务、运行中的成员、排队消息时被拒绝并说明原因）；归档后从团队列表消失、出现在已归档列表；恢复后回到列表，历史还在 |
| TM-3 | 回归 | 删除一个有未完成工作的成员；删除项目经理；删除一个空闲成员 | 前两者被拒绝并按名字说明原因；空闲成员可以删，团队目录里的用户文件不受影响 |
| TM-4 | 回归 | 一个工作目录已被另一个团队占用时，再建团队指向它 | 被拒绝，不接管 |
| TM-5 | 回归 | 团队设置里改思考强度、权限模式 | 下一轮生效；重启后保留 |
| TM-6 | 回归 | 在一个团队目录的子目录建第二个团队，再在它的上级目录建第三个；对已归档团队的目录的子目录也建一个 | 都能建；只有完全相同的目录被拒绝（同 TM-4） |
| TM-7 | 回归 | 团队空闲时把它的目录整个移走，停在成员会话页等 5 秒；再移回原处等 5 秒 | 不用回列表、不用重启：移走后显示「目录不在」、输入框禁用，目录没有被建回来；移回后自动恢复，能发消息 |
| TM-8 | 回归 | 团队刚工作过（引擎在跑）时，像资源管理器那样移走目录：先搬走里面的文件，再删目录 | 几秒内显示「目录不在」，空目录里没有被补写 `.cobot`，之后空目录能删掉；把项目放回原处后恢复 |
| TM-9 | 回归 | 团队缺测试工程师时，对项目经理说「招一个测试工程师」 | 出现招聘卡（不报「未知角色」）；同意后成员加入，项目经理回到空闲 |
