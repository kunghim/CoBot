# 每日预算

按本地时间的午夜起算的每日 Token 上限：设置里有默认值，团队和成员可以各设自己的上限（成员的上限不能超过所在团队的），
可以手动重置今日计数。达到上限时暂停新轮次，并出一张批准卡（一次暂停只出一张，按钮「保持暂停 / 重置并继续」）。接口：`GET/PUT /teams/{id}/budget`、`PUT /bots/{id}/budget`（`{limit}`，null 跟随默认）、`POST …/budget/reset`；设置里的预算必须同时给 `budgetScope`。

| ID | 层 | 步骤 | 期望 |
| --- | --- | --- | --- |
| BG-1 | 回归 | 设置 → 协作与预算：改默认每日上限，再改回；`GET /api/v1/settings` 回读 | 落库；界面里的数字单位与版本一致 |
| BG-2 | 回归 | 给一个团队设上限；给该团队一个成员设一个比团队上限更大的值 | 成员上限被拒绝或被限制在团队上限以内，并说明原因；团队上限小于成员已有的值时同样处理 |
| BG-3 | 回归 | 把一个团队的上限设得很小，发一条消息让它跑一轮 | 到达上限后新轮次被暂停，只出现一张询问卡；事件写明是谁的上限（团队或成员）；已开始的轮次不被打断 |
| BG-4 | 回归 | 在 BG-3 的暂停状态下手动重置今日计数 | 计数清零，暂停解除，新轮次可以继续；重置在重启后仍然有效 |
| BG-5 | 回归 | 上限设为 0（不限） | 不会暂停；没有使用数据的轮次不会被当成超限 |
