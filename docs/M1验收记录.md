# M1 验收记录（可运行产品骨架）

- 里程碑：M1；日期：2026-10-15。
- 平台/架构：Windows 10/11 x64（本机开发与验证）；headless Web 核心，桌面壳代码已提交、原生运行待测。
- Go/前端锁定版本：Go 1.25.12；Node 24.21.0 / npm 11.19.0；React 18.3、Vite 6.4、Tailwind 4、TanStack Query 5、i18next（zh-CN/en）；modernc.org/sqlite 1.38、goose 3.24.1；生成工具 oapi-codegen v2.4.1、openapi-typescript 7.13.0。
- Codex：本阶段未接入（引擎状态如实返回 `not_configured`，不模拟）。
- 运行 profile：全部测试使用 `.tmp` 与 `t.TempDir()` 临时数据根，不接触 `~/.cobot` 生产库。

## 实现范围

- Go module `github.com/kunghim/CoBot`；`cmd/cobot serve`（`mcp`/`hook` 按里程碑后续加入）。
- `internal/platform`：profile 路径（dev `~/.cobot-dev` / prod `~/.cobot` / `--data-root` 覆盖）、环境级单实例锁（O_EXCL + 存活探测 + 崩溃残留接管）、instance.json（不含授权秘密）、runtime 凭据（0600）。
- `internal/store/sqlite`：单连接池、WAL/foreign_keys/busy_timeout=5000/synchronous=FULL；goose 嵌入迁移；版本守卫（拒绝更高库版本）；升级前 `VACUUM INTO` 一致性备份（保留最近3份）；settings/events 查询。
- `internal/auth`：一次性 bootstrap 发行/兑换（60s、单次、仅存哈希）、内存页面会话（HttpOnly Cookie + CSRF）、桌面 Bearer（30分钟、可续）。
- `internal/api/http`：`{data,requestId}` / `{error:{code,messageKey,params},requestId}` 信封；精确 Origin/Host 校验（loopback-only、拒绝伪造 Origin 与非 loopback Host）；CSRF（cookie 写请求）；`/api/v1/status|session/bootstrap|auth/logout|settings(GET/PATCH)|snapshot|events(SSE)`；`/internal/v1/session/link`（runtime 凭据换新 bootstrap）；SPA 静态回退。
- `internal/events` + SSE：订阅在前、DB 游标查询在后，心跳/轮询兜底；持久事件可重放。
- `internal/app`：设置读写（revision 乐观并发、校验、事件同事务）、snapshot、事件分页；用户/Bot 身份服务端校验。
- 前端骨架：图标导航（首页/设置）、可收起团队列表与工作面板、真实空状态（无假数据、无未实现按钮）；设置页（语言、引擎路径与真实状态、成员/链上限、预算范围/token，全部真实持久化）；一次性链接片段兑换、桌面桥/开发链接兜底、401 重授权界面；zh-CN/en i18n；SSE（浏览器 EventSource / 桌面 Bearer fetch 流）。
- 桌面薄壳：`cmd/cobot-desktop`（Wails v2.15，`desktop`/`bindings` build tags 分离，bindings 模式零副作用）、`internal/desktop` 桥（Bootstrap/OpenDirectory/Quit、复用已运行核心的接管路径）；headless 构建不受 GUI 依赖影响。
- 工程链：`scripts/{dev,check,build,generate}.{ps1,sh}`、`.github/workflows/ci.yml`（web/core + Windows 桌面静态编译）、`api/openapi.yaml` + 生成的 Go DTO（`internal/contract`）与 TS 类型（`frontend/src/api/generated`，禁止手改）。

## 已知问题与偏离

- 本机 Go 发行副本（`gonavi-go1.25.12` GOROOT）曾缺失约 8k 个标准库源文件（含 `go/format`、`net/http/cookiejar`、`testing/fstest`），导致 oapi-codegen 等工具无法运行；已用官方 go1.25.12 src 包按缺失清单加性恢复（仅补缺失文件，未改动既有文件）。测试因此避开 `cookiejar`/`fstest`，改用仓库内最小实现（`internal/testutil`）。
- HTTP 层 DTO 当前与 `internal/contract` 生成类型结构一致但尚未全面改为引用生成类型；随 M2 接口扩展一并统一映射（domain 不直接成为公共 DTO）。
- 未偏离用户已确认决定；`cobot mcp`/`cobot hook` 未提前占位实现（分别随 M3/M4 交付）。
