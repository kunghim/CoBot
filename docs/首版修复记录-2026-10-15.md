### F2 执行时序、桥授权与恢复

- 19 个协作工具提供字段、必填项、枚举及说明，真实 MCP tools/list 和协议回归均覆盖；身份不进入模型参数。恢复 thread 显式携带 cwd、模型、角色、权限及桥配置。
- 派发按成员并行、同成员串行；唤醒信号合并且不丢失。停止取消 RPC 等待并遵守截止时间。启动响应只确认已接受事实，不覆盖审批/完成/未知状态；原生 turn/started 先绑定身份，重复的前驱完成通知不能结束后继。回调按发出事件的 runtime/epoch 处理，结束 turn 时使其未决定原生卡失效。
- 真实测试纠正了两项原假设：`auto` 并非协作工具免审批，CoBot 自有桥应使用 `approve`，命令/文件原生审批仍启用；已加载的 Codex thread 会保留 MCP 进程，resume 新环境变量不会替换它的旧令牌。第一版轮换令牌的实现因此在第二轮真实调用中失败，未被记为通过。
- 最终采用同一受管桥连接、按 Run 激活的执行授权和 Codex 原生 `_meta.x-codex-turn-metadata` 身份：桥只转发原生 thread/turn，服务端核对活动 Run/代际/会话，模型参数不能指定来源。Run 结束立即停用授权，闲置/过期请求被拒绝，只有宿主领取新 Run 才能重新激活；显式撤销不被下一轮静默恢复。核心重启重签发，凭据值仍只在内存/受管通道中。保留连接标识是适配引擎生命周期，不是让旧执行获得后继权限。
- 目录改绑与领取派发/启动 runtime 互斥，活动和 unknown Run 均拒绝改绑；旧 runtime 关闭后新启动使用新 cwd。恢复选项先查询精确旧 thread/turn 的终结事实；缺少身份或仍在执行时保留 unknown 和待决定卡，不消耗决定，不重跑。缺身份的卡提供禁用原因，前端展示在 F4 完成。
- 新发现 R26：modernc SQLite 1.38.0 在取消查询的特定时序泄漏结果集，导致关闭后数据库仍被占用；[上游修复](https://gitlab.com/cznic/sqlite/-/merge_requests/81)与本机源码、失败现象一致。锁定兼容 Go 1.25 的 1.46.2，补取消后继续读/检查点/关闭文件回归。原频繁失败的桥测试连续 10 次通过；没有更换数据库选型或升级系统 Go。
- 新发现 R27：原适配器把 MCP elicitation 等未支持请求也做成命令审批卡，回复形状错误。现在仅已验证的原生请求可生成卡；未支持的 elicitation 用其正确协议取消，其他未知请求明确拒绝。补独立协议回归。
- 追加 R25：真实重启发现旧 cookie 连前端 HTML 都会阻断，导致无法到达重新授权入口；公共静态壳和状态页现在可加载，业务 API 仍要求有效身份。补 HTML 深链接、旧身份及 API 权限回归。
- 已执行：`go test -count=1 ./internal/... ./tests/...`、`go vet ./internal/... ./tests/...`、OpenAPI Go/TS 重新生成，以及运行时/恢复/保留同一 MCP transport 的正反例。短 TTL 单测证明闲置授权不能自行恢复，前驱/错误 thread/撤销来源不能写入。
- 真实产品：隔离 profile 内 Codex 0.161.0 + gpt-6.1-sol；重启保留官方登录，同 Bot 连续两轮 get_context/remember 成功，两个不同正文均真实落库。真实中断返回 202，数据库记录精确 turn 为 interrupted，成员解除占用。测试只写忽略目录中的测试数据，没有操作用户日常 Codex 状态。

### F3a 任务派发、等待门禁与生命周期

- 新增迁移 00008，投递显式记录 taskId、来源 Run 与投递种类；旧任务指派和问题答案分开回填，普通用户消息不会因历史 run_id 字段被误认成任务。v7 业务对象升级及一致性备份回归通过，没有重写旧迁移。
- 取消任务、取消未送投递及其消息投影同事务；派发领取时重读任务、归属及成员存活状态，旧 queued 行也不能执行已取消/完成任务。确认完成与依赖投递激活同事务，避免完成已落库而后继永久停住。
- open Question 只阻塞相关自动派发；无 taskId 时约束提问成员。FIFO 在可派发输入间保持，普通用户新消息可以进入，但不回答原问题；显式回答/撤销才解锁，并唤醒相关成员。
- 开放问题纳入成员删除/团队归档/删除普查；删除和归档事务内复查。通用任务状态写入拒绝非法枚举、跳过确认的 done 和终态重开；消息重试核对接收者、发送者、类型及任务关联。
- 已执行：Go 全量未缓存测试通过，新增取消/等待/删除普查/终态/换目标反例与 v7 升级备份回归通过。R13 原子幂等、R10/R11 审批反馈与绑定继续在 F3b 处理；本子阶段不声称 F3 全部完成。
