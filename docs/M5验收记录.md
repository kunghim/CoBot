## 跨模块自审（M5d）发现与处理

1. **窄屏工作面板不可达**（I05 缺陷）：`hidden lg:block` 使面板在窄屏"状态打开却不可见、关闭入口又只在面板内部"。修复为覆盖式 + 窄屏默认收起（60d28fa）。
2. **nil 切片线格式**：创建任务/提交证据的响应曾把 nil 切片序列化为 null，前端 `.length` 崩溃。双侧修复（60d28fa）。
3. **15 个后端错误键无文案**：错误页会显示机器键名。全部补齐中英文（3e39613）。
4. **单连接死锁模式复查**：对 `internal/app` 全量窗口扫描"事务内使用 a.DB"，当前 0 处（本阶段改绑路径的两处已在开发中当场修复）。
5. **仓库卫生**：docs 子目录未入库；跟踪文件无密钥形状内容；契约生成无漂移（check 门）。

## 偏离说明（与方案 4.1 契约的差异）

- `POST /recoveries/{id}/decisions`：恢复卡的决定统一走 `POST /approvals/{id}/decisions`（同一张卡、同一 CAS、同一权限面），未另设平行路径；职责（恢复选择、不自动重跑）已由集成测试覆盖。
- `GET /authorizations` 的资源粒度为成员（撤销即撤销该成员全部桥凭据），未细分到单个令牌——令牌值从不外显，无法也不应按值寻址。
- 目录浏览以"直接子目录名"实现（服务端不列文件），比通用文件选择器更窄，符合"不提供任意读写"的边界。
