## 外部运行时（不在发行物内，需用户自备）

- Codex CLI（`codex`）：引擎进程由 CoBot 按用户设置的路径或 PATH 启动；版本证据见 docs/接入基线.md。其许可证属于 Codex 自身条款，不由本产品分发或代为声明。
- Git（可选）：仅用于团队目录的本地 exclude 幂等追加；非必需。

## 生成命令

```bash
go list -deps -f '{{if not .Standard}}{{.Module.Path}} {{.Module.Version}}{{end}}' ./cmd/cobot | sort -u
npm ls --prefix frontend --omit=dev --depth=0
```
