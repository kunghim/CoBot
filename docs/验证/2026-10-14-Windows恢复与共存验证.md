## 有限共存实验

程序见 [windows-coexistence.mjs](../../experiments/app-server/windows-coexistence.mjs)。只使用本机管道和 command/exec，不调用模型、不启动登录、不读取认证值、不创建新会话。使用独立 production/development 临时状态目录，不创建正式产品目录。

成功证据：`.tmp/app-server-spike/windows-coexistence-1791990560534/report.json`。

整个桌面再次重启后的补充证据：同目录 `post-desktop-restart.json`，passed=true、temporarySandboxOverride=false、readOnlyWriteBlocked=true、nativeConfigAndSetupUnchanged=true。

| 项目 | 结果 |
| --- | --- |
| 日常目录实例，私有实例启动前/同时运行/退出后 | 命令成功，readOnly 写入探针均拒绝 |
| 两个私有目录实例 | 各自写入并读回固定标记，内容正确 |
| 私有实例工作目录之外 | 写入拒绝，目标文件不存在 |
| 关闭并重启两个私有 app-server | 正常退出，重启后可读取各自已有标记 |
| 关闭并重启日常目录的额外 app-server | 命令成功，readOnly 写入仍拒绝；不是重启整个桌面应用 |
| 私有实例退出后再次重启整个桌面应用 | 新主进程保持 prefer_mxc=true；保存配置下受限命令成功、只读写入拒绝 |
| 日常目录状态检查 | config、setup_marker、setup_error 内容及 sandbox-bin ACL 均未变化 |
| 日常认证文件 | 仅比较大小和修改时间，均未变化；没有读取凭据值 |
| 私有认证及旧沙箱目录 | 未生成 auth.json 或 .sandbox-bin |

程序显式指定已验证的真实二进制及 windows.sandbox=mxc；不依赖 PATH 的 shim，不静默换成旧 elevated 或全权限。当前版本导出的 schema 仍支持 command/exec 的 sandboxPolicy 字段。

首次新探针失败证据保留在 `.tmp/app-server-spike/windows-coexistence-1791990501901/report.json`：探针把私有实例启动 cwd 设为公共测试根，随后将该根内部的兄弟文件误当作可写范围外。默认 workspaceWrite 包含服务启动 cwd；改为每个实例自己的工作目录后，写入拒绝检查通过。这是探针设置修正，不应描述为已发现协议忽略权限或引擎漏洞。

## 后续接入约束

- CODEX_HOME 隔离负责会话和状态归属，不保证 Windows 账号、服务、防火墙等系统资源隔离。
- Codex 适配器需要核对版本及沙箱能力；偏好参数不能代替明确选择和实际写入边界验证。不能假定所有已安装版本都支持相同参数。
- 普通启动不承担系统环境修复。遇到初始化失败，停止并报告；全局配置、权限或系统初始化调整另行取得用户授权。
- 历史 `shell-diagnostic.mjs` 默认阻止执行；其旧沙箱分支仅供明确授权的诊断，不能作为常规健康检查。
- 本轮恢复与有限共存的桌面重启闭环已完成。私有官方登录和真实模型工具仍需独立验收，不以 command/exec 的通过结果替代模型接入验证。
