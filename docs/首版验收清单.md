# CoBot 首版验收清单（逐项交付）

- 日期：2026-10-15；版本：0.2（共94项，阶段子项与关键缺口补齐）。
- 配套：[开发方案](首版开发方案.md)、[目录架构](首版目录架构.md)。
- 每项均为尚待产品实现的验收标准，不是通过记录。编码智能体不得预先勾选。

## 1. 使用规则与证据格式

每项报告：ID、产品 commit、平台与架构、Codex 版本/配置（不含秘密）、数据 profile、步骤、预期、实际、证据、通过/失败/阻塞。报告有日期，原始大文件放 `.tmp/`，文档放脱敏摘要。

自动化分类：U=单元，I=隔离 SQLite+假引擎集成，B=浏览器 E2E，R=真实 Codex 产品流程，P=真实平台安装运行。U/I/B 可常规 CI；R/P 使用明确测试团队和目录，不能调用/归档/删除用户已有会话，不在生产用户库注入故障。

前置接入无需重跑；本清单测的是实现后的产品功能。不能以实验通过替代对应 R 项，也不能只拿 fake 的 turn/completed 当真正产物证据。

通过要求包含反例。仅出现成功 toast 或截图不算后台权限、一致性、恢复验收。数据库检查只针对 CoBot 测试库，禁止借验收修改 Codex 数据库。

REQ-01～REQ-08是开发方案功能编号；A01～K03是本清单验收编号，两者不混用。阶段执行以开发方案5.0映射为准：只验当前已实现子场景，后续子项标未测，不因M1没有任务/记忆就迫使提前实现M4。

M1的A05使用settings旧库种子测迁移框架；M4/M5补Task/Message升级。A06中Bot身份使用隔离fake Principal测试，不要求M1已有MCP。J类在前期只测构建子项，最终M5测安装与发行全项。每个平台分别记录；Windows阶段通过不冒充macOS通过，未取得Mac不阻塞无关编码。
