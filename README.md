# CoBot

开源、本地运行的多 Agent 协作应用：CoBot 组织角色、任务、沟通与审批，业务操作交给外部 Agent。首版先做编程，目标是用 CoBot 开发 CoBot，后续面向办公、学习、创作等场景。

**当前阶段：需求讨论与接入验证，尚未实现产品。** 文档更新为 2026-10-14，讨论覆盖到第十五轮；以后会继续修改，不代表范围冻结或承诺已经支持某项功能。

## 文档约定

- **已确认**：用户明确同意的产品规则或设计方向。
- **建议**：根据讨论补充的候选做法，未确认前不当成硬要求。
- **待讨论**：需要继续决定的产品选择。
- **待技术验证**：设计有方向，目标环境的能力和可靠性尚未证明。

需求文档是当前产品状态的主要入口，技术方案承接它；界面细节维护在界面布局，历史依据维护在决策日志。产生新决定时同时更新受影响的正文与日志，不能只改历史记录。

资料最初在 `kunghim-ops` 工作站的 `brainstorm/cobot/` 中整理，本次迁入此项目。multibot 是已验证可行性的前身，本仓不会以迁文档为由修改、备份或清理其代码。Grok Bot 和 Orca 的原始研究仍保留在工作站研究模块，来源路径见迁移记录。

Go 后端已确认，支持 Windows/macOS 客户端及本机 Web；其他技术、许可证及发布细则待定。不建设云端业务。默认工作区与用户资源/成果位置正在调研，旧强制项目绑定不作为当前实现要求。当前有可运行的接入实验程序，没有可运行的 CoBot 产品服务；不要把交互草案或模拟 MCP 回执当成产品。本机 CLI 0.161.0 临时优先 MXC 后，四组正常接入实验通过，可以推进最小任务闭环。旧 elevated 路径仍初始化失败；通过证据限于已测配置，尚未完成产品验收。
