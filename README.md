# CoBot

基于 Codex 的本地多 Bot 协作工具：为一个工作目录创建团队，由队长组织成员完成软件开发任务，协作过程可查看，需要用户决定的动作通过审批卡处理。

**当前阶段：需求讨论与接入验证，尚未实现产品。** 文档更新为 2026-10-14，讨论覆盖到第十三轮；以后会继续修改，不代表范围冻结或承诺已经支持某项功能。

## 文档约定

- **已确认**：用户明确同意的产品规则或设计方向。
- **建议**：根据讨论补充的候选做法，未确认前不当成硬要求。
- **待讨论**：需要继续决定的产品选择。
- **待技术验证**：设计有方向，目标环境的能力和可靠性尚未证明。

需求文档是当前产品状态的主要入口，技术方案承接它；界面细节维护在界面布局，历史依据维护在决策日志。产生新决定时同时更新受影响的正文与日志，不能只改历史记录。

资料最初在 `kunghim-ops` 工作站的 `brainstorm/cobot/` 中整理，本次迁入此项目。multibot 是已验证可行性的前身，本仓不会以迁文档为由修改、备份或清理其代码。Grok Bot 和 Orca 的原始研究仍保留在工作站研究模块，来源路径见迁移记录。

技术栈、数据库、许可证、语言和平台优先级仍待决定。当前有可运行的接入实验程序，没有可运行的 CoBot 产品服务；不要把交互草案或模拟 MCP 回执当成产品。正常对话、并发路由、续聊、MCP 与文件审批已局部验证；原生 shell 在当前实验环境仍受 Windows 沙箱初始化错误阻塞。
